# Clash Verge Rev App v2.5.8

Windows x64 正式版。版本号与 Clash Verge Rev 的正式版本对齐，分支修复不另增版本号。

## 变更

- 修复 APP 节点切换时的额外停顿，避免重复更新整个运行配置。
- 保留节点来源身份及固定节点失效阻断；切换不再关闭其他 APP 或 TUN 组的连接。
- 连续点击节点保留最后一次选择，保存失败明确报错并尝试恢复原选择。
- 保留已确认的 APP 视图、首页开关、955px 默认窗口宽度及模式按钮布局。

## 发行

提供 NSIS 安装程序、SHA-256 校验文件及 Tauri 更新签名。更新签名不等于 Windows Authenticode 签名。同版本安装需要手动覆盖；以 Release 中的源码提交与校验值识别修复构建。

运行机制与边界见 [APP 路由契约](../APP_ROUTING.md)。
